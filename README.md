# tantuni 🌯

Tantuni ASCII art, served hot in your terminal.

```sh
npx tantuni
```

## Usage

```js
import { tantuni } from 'tantuni';

console.log(tantuni);
```

## FAQ

**Is this an actual tantuni?**
No. You cannot eat ASCII. We tried. The keyboard was not delicious.

**Does it come with ayran?**
Ayran is a peer dependency. You have to install it yourself.

**Why is the bundle size so small?**
Because we left out the cotton-seed oil. Your `node_modules` can't handle that much flavor.

**Can I get it with extra acı (hot pepper)?**
`npx tantuni --extra-aci` is accepted and completely ignored, just like when you ask for "a little" acı in Mersin and get a lot.

**Is it production ready?**
It has zero dependencies, zero tests, and zero calories. More production ready than most of your stack.
